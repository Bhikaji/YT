# Autonomous AI Cartoon Studio
## Comprehensive Technical & Licensing Audit of 22 Repositories

This document evaluates the 22 candidate repositories identified for integration into the Autonomous AI Cartoon Studio. Each repository is analyzed for architectural suitability, licensing constraints, Blender compatibility, hardware requirements, and its designated role (**CORE**, **OPTIONAL**, **REFERENCE**, **EXPERIMENTAL**, or **RESTRICTED**).

---

## Group 1: 3D Character Generation & Rigging

### 1. MPFB2 (MakeHuman Plugin for Blender 2)
- **Repository URL:** `https://github.com/makehumancommunity/mpfb2.git`
- **Pinned Commit Hash:** `9de0707fdc88438d7c53a1a2ac7937d9221e2431`
- **Description:** Complete procedural character generator inside Blender. Generates human/stylized meshes, parametric body controls, Rigify rigs, clothes, and facial shapekeys directly in `bpy`.
- **License:** **GPLv3** (Software) / **CC0 / Public Domain** (Base meshes and target assets).
- **Blender Compatibility:** Blender 3.6 to 4.2+ LTS.
- **Hardware Requirements:** CPU-only. Runs seamlessly on 4-core CPU without dedicated GPU.
- **Commercial-Use Rights:** **Fully Commercial.** Meshes generated by MPFB2 can be used in commercial animation, video games, and YouTube videos without royalties or copyleft taint on the output media.
- **Integration Role:** **CORE (Tier 1)**. Primary engine for procedural base character generation and Rigify bone binding.

### 2. MB-Lab
- **Repository URL:** `https://github.com/animate1978/MB-Lab.git`
- **Description:** Advanced character generator addon for Blender with parametric bone rigs, muscle simulations, and facial expressions.
- **License:** **GPLv3**.
- **Blender Compatibility:** Blender 2.80 - 3.6 (Community patches for 4.x).
- **Hardware Requirements:** CPU-friendly.
- **Commercial-Use Rights:** **Commercial.** Character models generated are free for commercial use.
- **Integration Role:** **OPTIONAL (Alternative to MPFB2)**. Secondary mesh morphing backup.

### 3. Awesome 3D Blender Characters
- **Repository URL:** `https://github.com/naranyala/awesome-3d-blender-characters.git`
- **Description:** Curated list of free, CC0, and open-source 3D character models, stylized rigs, and tutorials for Blender.
- **License:** **CC0 / MIT** (List metadata).
- **Blender Compatibility:** N/A (Documentation repository).
- **Hardware Requirements:** None.
- **Commercial-Use Rights:** Varies per linked asset; requires per-asset license check.
- **Integration Role:** **REFERENCE ONLY**. Used as an asset discovery catalog.

## Group 2: Animation, Retargeting & Motion Capture

### 4. Blender Animation Retargeting
- **Repository URL:** `https://github.com/Mwni/blender-animation-retargeting`
- **Pinned Commit Hash:** `424f08bd7e675619adf539209a1e8816c242c386`
- **Description:** Automated bone mapping and animation retargeting addon for Blender. Retargets BVH, FBX, and Mixamo mocap animations to any arbitrary character rig (including Rigify).
- **License:** **GPLv3**.
- **Blender Compatibility:** Blender 2.80 - 4.2+.
- **Hardware Requirements:** CPU-only. Blazing fast (calculates retargeting matrices in milliseconds).
- **Commercial-Use Rights:** **Fully Commercial.** Output animations have no copyleft attachment.
- **Integration Role:** **CORE (Tier 1)**. Essential for applying the 250+ parametric action library clips to custom character skeletons.

### 5. Blender Add-ons (Official Repository)
- **Repository URL:** `https://github.com/blender/blender-addons.git`
- **Description:** Official Blender Foundation addon repository containing Rigify, Import-Export formats (glTF, FBX, OBJ), and camera tools.
- **License:** **GPLv2 / GPLv3**.
- **Blender Compatibility:** Native 100% compatibility.
- **Hardware Requirements:** Standard Blender requirements.
- **Commercial-Use Rights:** **Fully Commercial.**
- **Integration Role:** **CORE (Tier 1)**. Provides native Rigify and camera export mechanics.

### 6. AnimStudio
- **Repository URL:** `https://github.com/Sheggyb/AnimStudio.git`
- **Description:** Blender animation manager for organizing clips, keyframe blocks, and facial acting presets.
- **License:** **GPLv3**.
- **Blender Compatibility:** Blender 3.x - 4.x.
- **Hardware Requirements:** CPU-only.
- **Commercial-Use Rights:** Commercial.
- **Integration Role:** **OPTIONAL**. Helper utility for animation library organization.

### 7. Anim Studio (DvaitAI)
- **Repository URL:** `https://github.com/DvaitAI-tech/anim-studio`
- **Description:** Web-based AI-assisted 2D/3D storyboard and animation sequencing tool.
- **License:** **MIT / Apache 2.0**.
- **Blender Compatibility:** External tool (connects via REST/JSON).
- **Hardware Requirements:** Lightweight.
- **Commercial-Use Rights:** Permissive.
- **Integration Role:** **EXPERIMENTAL**. Potential UI/timeline integration.

### 8. Deep Motion Editing
- **Repository URL:** `https://github.com/DeepMotionEditing/deep-motion-editing`
- **Description:** Deep-learning-based skeletal motion retargeting and style transfer (SIGGRAPH research).
- **License:** **Research-only (Non-commercial clause in dataset/models)**.
- **Hardware Requirements:** Requires PyTorch + CUDA GPU.
- **Commercial-Use Rights:** **RESTRICTED.** Academic dataset licenses prohibit commercial monetization on YouTube.
- **Integration Role:** **RESTRICTED / EXCLUDED from production.** (Replaced by `blender-animation-retargeting` which is 100% commercial and CPU-native).

### 9. PoseCap
- **Repository URL:** `https://github.com/CorridorTech/PoseCap.git`
- **Description:** Single-camera monocular markerless motion capture tool.
- **License:** **GPLv3** (Code) / Custom (Model weights).
- **Hardware Requirements:** Heavy GPU inference for real-time tracking.
- **Commercial-Use Rights:** Restricted by underlying pose estimation weights (e.g. MediaPipe/YOLO-Pose).
- **Integration Role:** **OPTIONAL / ASYNC ONLY**. For offline mocap recording from reference video clips.

### 10. vid2anim
- **Repository URL:** `https://github.com/mehulcode12/vid2anim`
- **Description:** Video-to-animation converter utilizing SMPL pose estimation to extract BVH files.
- **License:** **MIT / Research**.
- **Hardware Requirements:** CUDA GPU recommended.
- **Commercial-Use Rights:** Depends on SMPL non-commercial license.
- **Integration Role:** **EXPERIMENTAL**.

## Group 3: Facial Expression & Lip-Sync

### 11. Rhubarb Lip Sync
- **Repository URL:** `https://github.com/DanielSWolf/rhubarb-lip-sync`
- **Pinned Commit Hash:** `9b9573cd21b253c9ba58739bbd1aa0b50b991bff`
- **Description:** Professional command-line tool that analyzes speech audio files and generates timestamped visemes (A, B, C, D, E, F, G, H, X) for mouth blendshapes.
- **License:** **MIT License**.
- **Blender Compatibility:** Native shapekey integration via Python scripts.
- **Hardware Requirements:** **CPU-only.** Compiles and runs in seconds on 4-core CPUs.
- **Commercial-Use Rights:** **Fully Commercial.** Zero restrictions, zero royalties.
- **Integration Role:** **CORE (Tier 1)**. Fundamental component of the 3D facial performance pipeline.

### 12. WhisperX
- **Repository URL:** `https://github.com/m-bain/whisperX`
- **Pinned Commit Hash:** `b904f02b7e1f26fd10fb04840d655ff27e88e464`
- **Description:** Forced word-level alignment and speech recognition using Whisper + wav2vec2.
- **License:** **BSD 2-Clause**.
- **Hardware Requirements:** Can run on CPU using `faster-whisper` (int8 quantization).
- **Commercial-Use Rights:** **Fully Commercial.**
- **Integration Role:** **CORE (Tier 1)**. Used for generating precise word-level subtitle timings and forced phoneme alignment.

## Group 4: Speech & Voice Generation (Local TTS)

### 13. Piper TTS
- **Repository URL:** `https://github.com/OHF-Voice/piper1-gpl`
- **Pinned Commit Hash:** `46c3c71f9155c4f5bfb887845f524433fd02febc`
- **Description:** Extremely fast, local neural text-to-speech engine running on ONNX Runtime. Designed for Raspberry Pi and low-power CPUs.
- **License:** **GPLv3** (Engine) / **Open Voice Licenses** (Voices: CC-BY, Public Domain).
- **Hardware Requirements:** **100% CPU-compatible.** Runs faster than real-time (~0.15x) on Intel i5-8265U.
- **Commercial-Use Rights:** Commercial-safe voices available (e.g., LibriTTS, VCTK).
- **Integration Role:** **CORE (Tier 1 Local Fallback)**. Primary offline local TTS engine requiring zero GPU.

### 14. Kokoro TTS
- **Repository URL:** `https://github.com/hexgrad/kokoro`
- **Pinned Commit Hash:** `dfb907a02bba8152ca444717ca5d78747ccb4bec`
- **Description:** 82-million parameter open-weight TTS model with expressive, natural delivery.
- **License:** **Apache 2.0**.
- **Hardware Requirements:** Runs on CPU via ONNX Runtime / `kokoro-onnx` in near real-time.
- **Commercial-Use Rights:** **Fully Commercial.** Apache 2.0 license.
- **Integration Role:** **CORE (Tier 1)**. Highly expressive local dialogue engine for animated series.

## Group 7: Visual Generation & Environment Tools

### 20. OpenTopos
- **Repository URL:** `https://github.com/gaoypeng/opentopos`
- **Description:** Open-source digital elevation model (DEM) and procedural 3D terrain generator for landscapes.
- **License:** **GPLv3 / MIT**.
- **Hardware Requirements:** CPU-friendly for low-to-medium mesh resolutions.
- **Commercial-Use Rights:** Commercial.
- **Integration Role:** **OPTIONAL**. Generates outdoor mountain, island, and cavern terrains.

### 21. ComfyUI
- **Repository URL:** `https://github.com/comfyanonymous/ComfyUI`
- **Description:** Modular node-based generative AI workflow engine.
- **License:** **GPLv3**.
- **Hardware Requirements:** Highly CPU-constrained on Intel UHD 620 (takes 6–15 mins per frame).
- **Commercial-Use Rights:** Permissive (Model weights vary).
- **Integration Role:** **OPTIONAL / ASYNC ONLY**. Used for static concept art and thumbnail background stylization, decoupled from the critical video render path.

### 22. Wan 2.2
- **Repository URL:** `https://github.com/Wan-Video/Wan2.2`
- **Description:** 14B / 1.3B diffusion video generation model.
- **License:** **Apache 2.0** (Code) / Custom model weights.
- **Hardware Requirements:** **STRICT NVIDIA CUDA GPU (16GB–24GB VRAM minimum).** Incompatible with Intel UHD 620 iGPU.
- **Commercial-Use Rights:** Permissive code, but model weight usage subject to safety filters.
- **Integration Role:** **RESTRICTED / EXCLUDED from local execution.** Replacing 3D characters with diffusion video violates Rule 7 and is hardware-incompatible.
